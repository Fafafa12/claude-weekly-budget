# weekly-budget documentation

weekly-budget is a Claude Code plugin that turns your weekly Claude usage limit into a budget: you decide how the week is shared out across the days, and it shows where you stand, where your pace leads, and warns you when you run ahead.

The [README](../README.md) is the quick tour. These pages go deeper.
